# Stack research, 2026-10-19

Compiled by a research agent against live docs and npm. Summarised in DECISIONS.md; kept here for the sources.

## XState v5
- Pure `transition(machine, state, event)` and `initialTransition(machine)` since 5.19.0; `getNextTransitions(state)` since 5.26.0. `getNextSnapshot` is to be deprecated.
- Snapshots are machine objects; rebuild from JSON with `machine.resolveState({ value })`; persist with `getPersistedSnapshot()`.
- xstate 5.33.3: 46.8 kB min / 14.5 kB gzip. `xstate@6.0.0-alpha.70` exists.
- `TransitionConfig` has `guard`, `target`, `meta`, `description`; `StateNodeConfig` has `meta`, `description`, `tags`, `type`.
- Stately Studio imports `createMachine()` code and exports JSON/JS/TS/Mermaid; the inspector attaches to a running actor and is hosted. Neither consumes plain JSON as an embeddable editor.

## MCP
- Spec 2026-07-28: stateless, Streamable HTTP or stdio, old HTTP+SSE transport deprecated, `outputSchema` and `structuredContent` on tools, `isError` for domain errors, elicitation via `input_required` results.
- TypeScript SDK v2: `@modelcontextprotocol/server` 2.3.1, `/client` 2.3.1, `/node` 2.1.1, `/hono` 2.0.2. v1 `@modelcontextprotocol/sdk` 1.32.1 maintained at least six months after 2026-07-27.
- `createMcpHandler(factory)` returns `{ fetch }`; on Bun `export default handler` is the mount. Hono: `createMcpHonoApp()` then `app.all('/mcp', c => handler.fetch(c.req.raw, { parsedBody: c.get('parsedBody') }))`. Factory runs per request; keep state at module scope.
- Claude Code: `claude mcp add --transport http <name> <url>`; project scope writes `.mcp.json`. Claude Code negotiates 2026-07-28 with servers that support it. `_meta` hints: `anthropic/alwaysLoad`, `anthropic/requiresUserInteraction`, `anthropic/maxResultSizeChars`.

## Storage
- `bun:sqlite`: built in, cached prepared statements via `db.query()`, synchronous `db.transaction()`, WAL recommended, `strict: true`. macOS leaves `-wal`/`-shm` sidecars.

## Live updates
- `Bun.serve` has WebSocket with topic pub/sub and SSE via streaming `Response`; Hono `streamSSE`. Bun `idleTimeout` defaults to 10 s: use `server.timeout(req, 0)` or heartbeats.

## UI
- `@xyflow/react` 12.12.0: 187.9 kB min / 60 kB gzip. Docs recommend dagre (`@dagrejs/dagre` 3.1.1, 15.8 kB gzip) and advise against ELK (elkjs 0.12.0, 433 kB gzip).
- React 19.3.1, Vite 8.3.4 (Rolldown, ESM-only), Hono 4.13.13.
- Bun HTML bundler and fullstack dev server documented as work in progress.

## Headless evaluation
- `claude -p --output-format json`: returns `result`, `session_id`, `total_cost_usd`, `num_turns`, `permission_denials`, `structured_output` with `--json-schema`. `--bare` recommended for scripts; loads skills from `--add-dir`'s `.claude/skills/`. `--permission-mode dontAsk --permission-prompts none` for unattended runs.
- Agent SDK `@anthropic-ai/claude-agent-sdk` 0.3.304: `query({ prompt, options })`, skills from `<cwd>/.claude/skills/` and `additionalDirectories`.
- `claude plugin eval` (v2.1.269+): cases in `evals/<case>/{prompt.md,case.yaml,graders/*.md}`, graders regex / tool_used / tool_order / file_exists / llm / baseline, MCP tools mockable or `--allow-real-servers`.
