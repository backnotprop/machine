machine · identity sheet

machine is a web UI where you draw a process as a state machine; publishing it gives an agent a skill and a definition that a tool enforces step by step.

Each card shows one glyph at 64, 32 and 16 px, then in one colour (mono), then the lockup on dark and on white with a 16 px favicon. Blue is used on at most one part of each glyph.
