machine · identity, round three

Round two's Pull, redrawn so the blocks read as a state machine: each block is a state, each bar between blocks is a transition, and the one blue block is the current state.

How to read a card: the mark at 160 and 64 px, the 16 px favicon file at 8x with no smoothing, the macOS icon, the real 16 and 32 px files in browser tabs, and the product sidebar.

01

Pull

own 16 px drawing
Reads as
Three states stacked in order; the current one is slid out of the stack and lit.
Weak spot
Nothing joins the slabs: transitions are implied by order alone, so it is still a stack more than a machine.
16 px
Own drawing: 12 px slabs 2 px thick, the lit slab 3 px thick and out by 3 px (second pass; at 2 px it was a thin stripe). The scaled hero nearly holds, but its gaps fall between pixels.
02

Track

own 16 px drawing
Reads as
A block with a track cut along it; the current state sits lit in the track.
Weak spot
The near wall hides the foot of the lit block, and there is one state, not a sequence.
16 px
Own drawing: 2 px walls, a track one block wide, the lit block set toward the near end so the open end of the track shows (second pass). Scaled, the block is 3 px and the track is gone.
03

Start

own 16 px drawing
Reads as
A flat arrow on the ground feeds the first state; a bridge leads to the second, which is lit.
Weak spot
The arrow lies flat and reads as a wedge before it reads as an arrow; at 16 px the middle state is dropped.
16 px
Own drawing: a 6 px flat arrow and the lit 8 px block, nothing else. Scaled, the arrow is a grey smudge. An upright arrow was tried and read as a sail.
04

Turn

own 16 px drawing
Reads as
Three states on a path that turns a corner; the corner state is lit.
Weak spot
The bar into the front block is hidden behind it, so the three blocks pack into one lump.
16 px
Own drawing: three 8 px cubes with 1 px gaps and no bars (second pass; the bars were invisible at this size). The only mark that keeps three states at 16 px.
05

Path

own 16 px drawing
Reads as
Three states in a row joined by two transitions; the middle one is lit.
Weak spot
Long and low: it fills a third of a square, and at 16 px only two blocks fit.
16 px
Own drawing: two 8 px cubes and one bar, the second lit. Three cubes do not fit on this diagonal.
06

Steps

own 16 px drawing
Reads as
Three states stepping down left to right, each transition a short bridge; the middle step is lit.
Weak spot
At 16 px it is two blocks with a 3 px step: nearly the same favicon as Path.
16 px
Own drawing: two 8 px cubes, the grey one 3 px higher, a 1 px bridge at the lit top.

Faces

hero holds at 16 px

Verdict

1

Pull

The best favicon here and the owner's pick, but it is still a stack, not a machine: it only reads as states in order once someone says so, and nothing on it is a transition.

2

Track

The only mark that says "on the rails" without words, and at 16 px it is a blue block in a grey trough; but it shows one state, not a sequence, and the near wall hides the foot of the block.

3

Turn

The only mark that is still three states with one lit at 16 px; at every larger size it looks like a pile of cubes, and the bar into the front block is hidden behind it.
